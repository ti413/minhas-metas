# Screenshots necessários para a Play Store

Crie as seguintes imagens com dimensões 390x844px (proporção iPhone/Android padrão):

- screenshot-registro.png  → Tela principal de registro das metas do dia
- screenshot-calendario.png → Tela do calendário mensal
- screenshot-dashboard.png  → Tela do dashboard com gráficos

Como tirar os screenshots:
1. Abra o app no Chrome (desktop)
2. Abra DevTools (F12) → Toggle Device Toolbar
3. Selecione dimensão customizada: 390 x 844
4. Tire o screenshot: DevTools → ... → Capture screenshot

Salve os arquivos nesta pasta com os nomes exatos acima.
