Política de Privacidade

Resumo

O app Minhas Metas não coleta, armazena nem compartilha nenhum dado pessoal em servidores externos. Todos os seus dados ficam armazenados exclusivamente no seu próprio dispositivo.

1. Quais dados o app utiliza?

O app armazena localmente no seu dispositivo apenas:

  • Registro diário das suas metas (concluídas ou não)
  • Valores numéricos que você inserir (km corridos, horas de sono, litros de água)
  • Histórico de dias anteriores para exibição no calendário e dashboard

Esses dados são salvos usando o localStorage do navegador, uma área de armazenamento local do seu dispositivo.

2. Os dados são enviados para algum servidor?

Não. O app funciona completamente offline e não possui backend próprio. Nenhum dado seu é transmitido pela internet para servidores de terceiros ou nossos.

3. O app usa cookies ou rastreadores?

Não. O app não utiliza cookies, pixels de rastreamento, analytics ou qualquer ferramenta de monitoramento de comportamento.

4. Recursos externos

O app carrega ícones visuais a partir de um CDN externo (cdn.jsdelivr.net), que é necessário para exibir os ícones da interface. Essa requisição não transmite dados pessoais.

5. Como excluir seus dados?

Como os dados ficam apenas no seu dispositivo, você pode removê-los a qualquer momento:

  • No navegador: Configurações → Privacidade → Limpar dados do site
  • No app instalado: Desinstalar o aplicativo remove todos os dados

6. Menores de idade

O app não coleta dados de nenhum usuário, incluindo menores de idade. Não há cadastro, login ou envio de informações pessoais.
